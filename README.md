# The Confidence Rebirth

Link in bio VSL site for theconfidencerebirth.com. Single file: `index.html`.

## Before launch
- Lead CRM: deploy `apps-script/Code.gs` as a web app from the Leads Sheet (steps at the top of the file), then paste the /exec URL into `PAY.hook` in main/index.html. It logs applications and the course waitlist.
- `LINKS` (bottom of index.html): paste the real Circle signup, Circle paywall and Tally links.
- `NEXT_WORKSHOP`: set the next free workshop date each month (ISO date with time zone offset).
- VSL: replace the `#vsl` button with the Bunny or Vimeo embed once filmed.
- Legal pages: privacy, terms, refunds.
